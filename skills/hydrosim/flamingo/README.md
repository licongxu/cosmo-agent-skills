# FLAMINGO data skills

Reference skills for the [FLAMINGO data release](https://dataweb.cosma.dur.ac.uk:8443/flamingo/index.html).
Each skill is factual inventory and usage guidance, not copy-paste code. For loading
data, follow the portal pages **How to use this service** (web interface, Python
module, examples).
