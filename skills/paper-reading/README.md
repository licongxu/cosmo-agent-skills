# skills/paper-reading/

Reading the literature — turn a paper into a durable, critical research note.
Complements [paper-writing/](../paper-writing/) (producing manuscripts) and
[plotting/](../plotting/) (figure QA).

| Skill | Use when |
|-------|----------|
| [paper-deep-reading](paper-deep-reading/SKILL.md) | Given a title/DOI/arXiv ID/URL/PDF, or asked to read closely, extract contributions, analyze experiments, critique, compare related work, or maintain a paper-reading index |

**Design:** the note is the deliverable, grounded in the paper's actual text.
Discovery uses the valency MCP and `WebFetch` (both verified against
[arXiv:2006.12566](https://arxiv.org/abs/2006.12566)); the note format lives in
[paper-deep-reading/references/note-schema.md](paper-deep-reading/references/note-schema.md)
with a worked example in
[paper-deep-reading/references/example-note.md](paper-deep-reading/references/example-note.md).

Method is field-general; the structured reading scaffold follows Cooke et al.
(2020), [arXiv:2006.12566](https://arxiv.org/abs/2006.12566).
