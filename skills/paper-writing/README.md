# Paper-writing skills

Manuscript planning and drafting (Chamba, Knapen & Black 2022 — optional local
PDFs in `../ref_papers/`, gitignored), export figures, validate results, compile
LaTeX, VLM audit.

| Skill | Use when |
|-------|----------|
| [paper-writing-workflow](paper-writing-workflow/SKILL.md) | Plan → draft → compile → VLM (orchestrator) |
| [manuscript-writing-style](manuscript-writing-style/SKILL.md) | IMRaD prose, tone, captions, English mechanics |
| [scientific-plotting](scientific-plotting/SKILL.md) | Vector PDF figures at column width |
| [results-check](results-check/SKILL.md) | VLM + numeric check after plots or saved arrays |
| [vlm-figure-audit](vlm-figure-audit/SKILL.md) | Visual QA on figures, tables, PDF pages |
| [paper-layout-review](paper-layout-review/SKILL.md) | Iterative float/equation layout clash fix |
| [research-figure-manifest](research-figure-manifest/SKILL.md) | Figure provenance and validator status |

**Typical order:** workflow → style while drafting → plotting → results-check →
manifest → compile → vlm-figure-audit → paper-layout-review.
